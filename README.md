## 🎯 實驗核心流程與學習筆記

根據指定文章的教學，我們成功在 Google Colab 上演練了操作外部 AI 專案與管理雲端環境的完整流程：

1. **啟用 GPU 硬體加速**：AI 訓練需要強大算力，我們透過變更 Colab 執行階段類型，成功啟用了免費的 Tesla T4 GPU 資源。
2. **使用 Linux 魔法命令**：學習到了在 Jupyter 環境下使用 `!` 與 `%` 來控制系統背景（例如使用 `!nvidia-smi` 檢查顯示卡、`%cd` 或 `%pwd` 管理與切換專案路徑）。
3. **雲端硬碟挂載（Google Drive）**：利用 `drive.mount("/content/drive")` 代碼，實現了讓雲端運算主機直接讀取個人雲端硬碟檔案的功能。
4. **專案管理與環境配置**：理解了如何透過 `!unzip` 解壓專案包，以及未來如何使用 `!pip install -r requirements.txt` 一鍵安裝 AI 專案所需的套件依賴。
